# Kairos Market Lab

**Standalone, public, fully synthetic market simulator.** No connection to Kairos AGI runtime, exchanges, real money, real market data, external AI APIs or credentials.

## О проекте

Это автономная лаборатория для исследования механики рынка. Цены **возникают из исполнения виртуальных заявок** в локальном лимитном стакане. Это не генератор готовых свечей и не торговый бот.

**Первый воспроизводимый эксперимент — LQ-001: sudden bid-liquidity withdrawal.** Мы запускаем два искусственных рынка на **одной и той же ленте событий**. В контрольном случае продажи исполняются по исходной ликвидности; в экспериментальном случае непосредственно перед одинаковой агрессивной продажей отменяем 85% заявленного BUY-объёма на восьми верхних ценовых уровнях. Затем сравниваем VWAP, проскальзывание, исполненный объём и глубину стакана.

Все участники, инструменты (`VCOIN/VCU`), балансы и котировки синтетические. Результат не является прогнозом настоящего рынка.

## Быстрый запуск

Требуется Python 3.10+; внешние зависимости не нужны. Из корня репозитория:

```bash
python -m market_lab
python -m unittest discover -s tests -v
```

На Windows можно использовать `py -3.12 -m market_lab` и `py -3.12 -m unittest discover -s tests -v`.

После запуска в `artifacts/lq001/` появятся:

- `results.json` — параметры, входной hash, результаты двух сценариев;
- `timeseries.csv` — ряд цен, стакана, объёмов;
- `report.html` — автономная визуализация, открывается без сервера и интернета.

Пример параметров:

```bash
python -m market_lab --seed 42 --ticks 150 --shock-tick 80 \
    --cancel-percent 85 --cancel-levels 8 --sell-qty 26
```

## Границы первой версии

- Ценовой тик = `0.1 VCU`; объёмы = целое число виртуальных единиц; котировки в целых тиках без округления денежного ledger.
- В стакане реализованы пассивные лимитные заявки, ценово-временной приоритет, рыночные ордера, частичное исполнение, отмена ликвидности, проверка сохранения количества виртуальных единиц.
- 1 000 агентских **идентификаторов** доступны генератору; каждый обычный тик создаёт одно случайное действие, а не 1 000 заявок. Агентский капитал и балансы пока не моделируются.
- Для контрольного сравнения действия агентов генерируются **до запуска сценариев** и воспроизводятся без адаптации к новой цене. Поэтому это тест механики стакана, **не** реалистичная поведенческая модель кризиса.
- Комиссии, реальные биржевые ограничения, взаимодействие с реальными счетами, LLM, свечи OHLCV и сетевой UI пока **не** реализованы. Последующие этапы изложены в `docs/TECHNICAL_SPEC.md`.

## Безопасность

- Нет клиента биржи, HTTP, WebSocket, сетевых функций, SDK или работы с секретами.
- Нельзя отправить ордер на реальную биржу: никаких путей исполнения на внешней площадке нет.
- Нет зависимостей или импортов из `Kairos_AGI` / `kairos_next`.
- Режим данных всегда `SIMULATED`; программа записывает только локальные файлы результатов.

Лицензию можно добавить после отдельного решения владельца. Публичность репозитория сама по себе не означает предоставления прав на использование кода третьими лицами.
